Meterlet 0.3.0 requires the official CLIs and reads Claude Code usage as structured data.

- The CLI bundled with the ChatGPT/Codex desktop app and Claude desktop's downloaded Code runtime are no longer used. Install Codex CLI and Claude Code CLI, or choose the executable in Settings.
- Claude Code usage comes from the structured output of `claude -p "/usage"`. Claude Code 2.1.273 or later is required; older versions show an update prompt.
- Fixes the missing Fable row that appeared when the CLI redrew its usage screen.

Meterlet 0.3.0 では公式 CLI を必須にし、Claude Code の使用量を構造化データとして取得します。

- ChatGPT / Codex デスクトップアプリ内の CLI と、Claude デスクトップが取得した Code 実行プログラムは使用しなくなりました。Codex CLI と Claude Code CLI をインストールするか、設定で実行ファイルを指定してください。
- Claude Code の使用量は `claude -p "/usage"` の構造化出力から取得します。Claude Code 2.1.273 以降が必要で、古いバージョンでは更新案内を表示します。
- CLI が使用量画面を再描画した際に Fable の枠が表示されない問題を修正しました。
