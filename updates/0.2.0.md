Meterlet 0.2.0 adds updates from GitHub.

- Check for Updates from the menu bar’s right-click menu or Settings.
- Detects the Codex/ChatGPT desktop app’s CLI and Claude desktop’s downloaded Code runtime. Claude Code may require separate sign-in.
- Retries with the desktop runtime when the installed CLI requires sign-in.
- Optional daily update checks. Review updates before installing.
- Fixes popovers extending beyond the screen and prevents duplicate instances.

Meterlet 0.2.0 では、アプリからアップデートできるようになりました。

- メニューバーの右クリック、または設定から「更新を確認…」を選べます。
- Codex / ChatGPT アプリ内の CLI と、Claude デスクトップが取得した Code 実行プログラムを自動検出します。Claude Code は別途ログインが必要な場合があります。
- CLI が認証エラーになった場合は、デスクトップ版の実行プログラムでも取得を試します。
- 1日ごとの自動チェックを設定できます。インストールは更新内容を確認してから実行します。
- ポップアップの画面外へのはみ出しと、アプリの二重起動を修正しました。
