Meterlet 0.2.2 refines what the menu bar and the usage panel show.

- The menu bar shows weekly usage by default. Choose a different window for each provider in Settings.
- Claude Code shows the current session, this week, and this week's Fable limit, each with its reset time.
- Codex Spark limits are no longer shown.

Meterlet 0.2.2 では、メニューバーとパネルの表示内容を見直しました。

- メニューバーは既定で週間枠を表示します。サービスごとに表示する枠を設定で選べます。
- Claude Code は「現在のセッション」「今週」「今週の Fable」の 3 つの枠を、それぞれのリセット日時つきで表示します。
- Codex Spark の枠は表示しなくなりました。
