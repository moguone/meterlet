Meterlet 0.2.1 fixes Claude Code usage collection with recent CLI releases.

- Works with Claude Code 2.1.273. Signed-in users no longer see the "complete the CLI setup" message caused by the CLI's first-run screen.
- Loads plan usage again. A network restriction Meterlet applied also blocked the `/usage` data.
- Answers the CLI's folder trust prompt for Meterlet's own empty probe folder and waits for the CLI to be ready before requesting usage.
- Verified with a signed-in Claude Max account.

Meterlet 0.2.1 は、最近の Claude Code CLI で使用量を取得できない問題を修正しました。

- Claude Code 2.1.273 に対応しました。ログイン済みでも「初期設定を完了してください」と表示されていた問題を修正しています。
- Meterlet 側の通信制限が `/usage` のデータ取得まで止めていたため、制限を見直してプラン使用率を再び取得できるようにしました。
- Meterlet 専用の空フォルダに対する CLI の信頼確認に自動で応答し、CLI の準備が整ってから使用量を要求します。
- Claude Max のログイン済みアカウントで動作を確認しました。
